# References

The documents behind this project. The PDFs and the team's internal documents are not in this repository;
cite or request them as below.

**Reference paper** (the study this team project builds on):
Ahmad, H., Bhuiyan, I., Bhuiyan, T. and Hoque, A. (2026). Scalable and interpretable fraud detection in
FinTech: Evidence from a hybrid TabNet–Graph neural network framework. *The Journal of Finance and Data
Science*, 12, 100203. <https://doi.org/10.1016/j.jfds.2026.100203>

**Models used here:**
- Gorishniy, Y., Rubachev, I., Khrulkov, V. and Babenko, A. (2021). Revisiting deep learning models for
  tabular data. *NeurIPS 2021*. (FT-Transformer)
- Hamilton, W. L., Ying, R. and Leskovec, J. (2017). Inductive representation learning on large graphs.
  *NeurIPS 2017*. (GraphSAGE)

**Team documents (internal, not published):** the team plan (`Team_plan_graph_vs_V.pdf`, 21 October 2026),
which fixes the split, the graph, the column sets, the training rules and the hand-in format, and the team's
code style guide (`CODE_STYLE_GUIDE.md`). Page numbers such as "team plan p. 4" in the code and reports refer
to the team plan; `reports/plan.md` lists every rule from it that applies here and where the code follows it.
